# GitHub Projects GraphQL

Use the repository's GitHub CLI session or GraphQL client to run the mutations described in `SKILL.md`.

## Placeholders

- `resolve-owner` returns the org or user node ID.
- `list-boards` enumerates existing boards.
- `create-board` creates a new board.
- `update-board` updates visibility and description.
- `link-repo` links a repository.
- `create-field` adds a board field.
- `create-view` adds a board or table view.
- `add-item` adds an issue or PR.
- `add-draft` adds a draft item.
- `update-item-field` sets field values after the item exists.
