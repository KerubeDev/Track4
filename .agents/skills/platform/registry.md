# Registry Vocabulary

Canonical registry concepts for the Skills platform:

- Skill Registry: canonical inventory and metadata
- Capability Registry: what each Skill can do
- Context Registry: which context packs exist and when to use them
- Artifact Registry: which artifact types are valid and who consumes them
- Execution Registry: what ran, with what inputs, and what result

The registry is a catalog and validation boundary, not a hidden runtime.
