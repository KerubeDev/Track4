# Triage Briefing

## Standard flow

- classify the item
- verify the claim
- pull in domain vocabulary
- produce a durable agent brief when the item is ready
- keep prior decisions visible so the next agent does not re-open them

## Operational goals

- keep incoming work in a stable state
- avoid re-litigating prior decisions
- make the next agent's job explicit
- preserve the smallest amount of context that still explains the decision
