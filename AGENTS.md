# Agent guide

## Agent skills

### Issue tracker

GitHub Issues in `KerubeDev/Track4`, operated with the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default canonical roles: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`, plus the type labels `bug` / `enhancement`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` at the repo root plus `docs/adr/`. See `docs/agents/domain.md`.
